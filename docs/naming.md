# Preliminary Portico Naming Check

**Status:** Selected working name, not legally cleared

**Checked:** 2026-08-03

`Portico` fits the product metaphor: a Portal is a private doorway to a local
app. The name is nevertheless crowded in software and adjacent services.

Examples found in a preliminary web search include:

- [portico.app](https://portico.app/), an active commercial real-estate
  software product;
- [Portico: My Travel Planner](https://apps.apple.com/us/app/portico-my-travel-planner/id1531925764)
  on Apple's App Store; and
- [Portico](https://apps.apple.com/gb/app/portico/id1002307298), a payroll and
  HR application on Apple's App Store.

These examples do not establish whether the macOS developer-networking use is
legally available, but they make collision and discoverability risk material.
Before public branding or a paid release:

1. Search current UK, EU, US, and other intended-market trademark registers
   for relevant software, networking, and hosted-service classes.
2. Review unregistered commercial uses, domains, package registries, and app
   stores for confusingly similar developer tools.
3. Have qualified trademark counsel assess registrability and infringement
   risk.
4. Confirm availability of the intended product domain, bundle identifier,
   social names, and Homebrew cask token.

Until that work is complete, documentation should say: **Portico is the
selected working name and has not been legally cleared.**
